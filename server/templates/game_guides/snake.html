This starter reconstructs both snakes from the history and chooses an immediately unoccupied neighboring cell. It works with both Snake and Mini Snake by reading the supplied dimensions. It does not predict the opponent's next move.

import json
import random
from collections import deque

# Snake coordinates: x is the row, y is the column (both one-based).
DELTA = [(-1, 0), (0, 1), (1, 0), (0, -1)]

def grows(turn):
    # Zero-based turn: 0..24 grow, then 27, 30, 33, ...
    return turn <= 24 or (turn - 24) % 3 == 0

def advance(snake, direction):
    dx, dy = DELTA[direction]
    x, y = snake[0]
    snake.appendleft((x + dx, y + dy))

def main():
    data = json.loads(input())
    initial = data["requests"][0]
    height, width = initial["height"], initial["width"]
    start = (initial["x"], initial["y"])
    other_start = (height, width) if start == (1, 1) else (1, 1)
    mine, opponent = deque([start]), deque([other_start])
    obstacles = {(cell["x"], cell["y"])
                 for cell in initial.get("obstacle", [])}

    for turn, (my_move, their_move) in enumerate(
            zip(data["responses"], data["requests"][1:])):
        if not grows(turn):
            mine.pop()
            opponent.pop()
        advance(mine, my_move["direction"])
        advance(opponent, their_move["direction"])

    head = mine[0]
    if not grows(len(data["responses"])):
        mine.pop()
        opponent.pop()
    occupied = obstacles | set(mine) | set(opponent)
    options = []
    for direction, (dx, dy) in enumerate(DELTA):
        target = (head[0] + dx, head[1] + dy)
        if (1 <= target[0] <= height and 1 <= target[1] <= width
                and target not in occupied):
            options.append(direction)
    direction = random.choice(options or [0, 1, 2, 3])
    print(json.dumps({"response": {"direction": direction}}))

if __name__ == "__main__":
    main()
{% endcall %} {% call section('I/O Format Specification', 'io-spec') %}

Read one JSON object with requests and responses from stdin. Output one JSON object with a response object containing an integer direction.

Coordinates and input history

  • Snake uses one-based coordinates: x is the row (1–height, downward) and y is the column (1–width, rightward). This differs from the board games.
  • requests[0] contains height, width, your starting x/y, and obstacle, an array of blocked coordinates. Your snake starts at (1,1) or (height,width); the opponent starts at the opposite corner.
  • requests[1:] contains the opponent's previous {"direction": integer} moves. responses contains your own previous moves, without the outer response wrapper. Pair responses[i] with requests[i + 1] to reconstruct completed turn i.
{
  "requests": [
    {"height": 10, "width": 11, "x": 1, "y": 1, "obstacle": [{"x": 4, "y": 7}, {"x": 7, "y": 5}]},
    {"direction": 3}
  ],
  "responses": [{"direction": 2}]
}

Output

{"response": {"direction": 1}}

Directions are 0=up, 1=right, 2=down, 3=left. The example moves right. A direction must be an integer in 0–3.

{% endcall %} {% call section('Regulations', 'regulations') %}
  • Two snakes begin with length 1 at opposite corners. Both players choose a direction each turn; each head advances one cell.
    • {% if guide_game == 'Mini Snake' %}
  • Mini Snake uses a fixed 10-row × 11-column map with randomly generated, centrally symmetric obstacles. Movement, growth, and the Bot protocol are the same as Snake.
    • {% else %}
  • Snake generates a map with 10–13 rows and 11–17 columns, with an odd sum of height and width and centrally symmetric obstacles. Read the actual dimensions from the input.
    • {% endif %}
  • There is no food. Snakes grow every turn for turns 1–25, then on turns 28, 31, 34, and so on. On other turns, both tails are removed before moves are checked, so a vacated tail cell can be entered.
  • Moving outside the map, into an obstacle, or into either snake's remaining body kills the snake. If both heads enter the same cell, both snakes die.
  • If one snake dies, the survivor wins. If both die on the same turn, the game is a draw. The platform ends surviving matches at 200 turns as a draw.
  • Invalid direction values or malformed responses forfeit the game. Leaving while the Human seat is waiting also forfeits.
