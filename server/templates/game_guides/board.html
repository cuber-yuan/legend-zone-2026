import json
import random

COLS, ROWS = {{ cols }}, {{ rows }}

def main():
    data = json.loads(input())
    board = [[0] * COLS for _ in range(ROWS)]
    for move in data["move_history"]:
        board[move["y"]][move["x"]] = move["player"]
{% if is_connect4 %}
    columns = [x for x in range(COLS) if board[0][x] == 0]
    print(json.dumps({"x": random.choice(columns)}))
{% else %}
    options = [(x, y) for y in range(ROWS) for x in range(COLS)
               if board[y][x] == 0]
    x, y = random.choice(options)
    print(json.dumps({"x": x, "y": y}))
{% endif %}
if __name__ == "__main__":
    main()

Board and input

The board has {{ cols }} columns and {{ rows }} rows. Coordinates are zero-based: x increases left to right (0–{{ cols - 1 }}), y increases top to bottom (0–{{ rows - 1 }}). Index cells as board[y][x].

  • move_history: every completed move, in order. Each entry contains integer x, y, and player (1={{ first }}, 2={{ second }}). It is empty on the first move.{% if is_connect4 %} The stored y is the row where the disc landed.{% endif %}
  • your_side: 1 for {{ first }}, 2 for {{ second }}. Either side can be your bot.
